# Contributing to the MPATW Wiki

Thanks for helping! The full guide, with step-by-step instructions and a formatting cheat sheet, is on the wiki:
**https://imp4ncake.github.io/mpatw-wiki/contributing/**

## The short version

1. Click the edit button on any wiki page, make your change and open a pull request.
2. New pages start from `templates/page-template.md` and must be added to `nav` in `zensical.toml`.
3. A maintainer reviews every change before it goes live.

## Rules

1. Only add information you have checked in the game.
2. Add a date to anything that changes (codes, prices).
3. No personal information about players.
4. No exploits, hacks or leaks.
5. Use your own screenshots, kept small, in `docs/assets/images/`.
6. Write in English and keep content suitable for all ages.
