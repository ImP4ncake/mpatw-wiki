## How to redeem a code

<div class="mp-steps" markdown>
<div class="mp-step" markdown="span">:lucide-layout-grid: In the game, click the **four squares** icon on the left of the screen</div>
<div class="mp-step" markdown="span">:lucide-settings: Open **SETTINGS**</div>
<div class="mp-step" markdown="span">:lucide-keyboard: Type the code in **Enter code for rewards** and press **Enter**</div>
</div>

!!! tip "Type it exactly"

    Codes are **case sensitive**: type them exactly as written, in CAPITAL letters.
