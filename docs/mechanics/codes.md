# Codes

Codes give free rewards such as coins or Lucky Tokens. New codes are usually shared in the game's official **community server**, and redeeming one from there gives the **Coder** badge.

## How to redeem a code

1. In the game, click the **four squares** icon on the left side of the screen.
2. Open **SETTINGS**.
3. Type the code into the **Enter code for rewards** box and press **Enter**.

!!! tip

    Codes are **case sensitive**: type them exactly as written, in capital letters.

## Codes

| Code | Reward | Status |
