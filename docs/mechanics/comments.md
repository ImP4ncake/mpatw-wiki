# Comments

You can leave **comments** on the profiles of the players you interact with, and they can leave comments on yours. Comments are a nice way to say thanks after a good conversation, together with some [reputation](reputation.md).

!!! warning "Be respectful"

    Comments are public. Don't post personal information about anyone (including yourself), and don't use comments to harass people. Report abuse with Roblox's built-in tools: see [Report a Player](../community/reporting.md).

!!! info "In the rules"

    Comments count as something you **say**, so every rule about what you say applies to them too: see the [Rules](../community/rules.md).
