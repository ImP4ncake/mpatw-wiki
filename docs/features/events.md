# Seasonal events

The game runs limited-time events for holidays and special occasions. Each one comes with a **[LIMITED]** badge that can only be earned while the event is running.

| Event | Limited badge | How it was earned |
|---|---|---|
| Christmas | Claim The Christmas Gift | Give a gift during the Christmas event |
| Valentine's Day | Loved | Own or receive the Valentine's Pack |
| Saint Patrick's Day | Blessed | Roll **7777** on the Saint Patrick's Lottery |
| April Fools' Day | Win The Lottery? | A joke badge (its description hints at checking the date) |
| Easter | Easter Collector | Find all **50 Easter Eggs** |
| Halloween | Trick or Treat! | Win a special treat at the Spooky Shed |
| 2026 World Cup | WC2026 | Guess a winning team |

The **[LIMITED] Valentine's Pack** gamepass (emote, balloon, title and effect) was sold during the Valentine's event and is not for sale outside it.
