# Servers

Each server holds up to **65 players**.

## Voice and no-voice servers

The game offers two kinds of public servers:

- **Voice chat servers**, where you can talk to people out loud using Roblox voice chat.
- **No voice chat servers**, for players who prefer text chat only.

!!! note

    Using voice chat on Roblox requires that your Roblox account is eligible for it. Check Roblox's own help pages for the current requirements.

The **Voice Changers** gamepass adds several voice effects. It is currently not for sale.

## Custom servers

Anyone can create a **custom server** that other players can join. The creator of a custom server gets access to an **admin panel** to customize it.

In a custom server, the owner can make **all trolls and items free** for everyone in that server.

## Community server

The game has an official **community server**, where the game rules are posted. It is also where you can find:

- codes (redeeming one gives the **Coder** badge, see [Codes](../economy/codes.md));
- community events (winning one gives the very rare **Winner** badge).

## Moderators

The game has its own moderators. Becoming a game mod gives the **Honored** badge.
