# Admin Panel

The **Admin Panel** is available to the owner of a [custom server](custom-servers.md). One of its options makes all trolls and items free for everyone in the server.

!!! info "In the rules"

    **Fake Donation** from the Admin Panel doesn't change any stats, so it isn't bannable ([c2](../community/rules.md#c2){ .mp-rule }). Covering the map because an Admin used a Size Change command on you isn't bannable either ([c6](../community/rules.md#c6){ .mp-rule }).
