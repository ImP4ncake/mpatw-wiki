# Custom Servers

Anyone can create a **custom server** that other players can join. Custom servers live in a separate place called **[CUSTOM] 18+ Meet People Across The World**.

- The creator of a custom server gets access to an [Admin Panel](admin-panel.md).
- The owner can make **all trolls and items free** for everyone in that server.
