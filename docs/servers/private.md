# Private Server

<p class="mp-lead">Want a server of your own? A <b>private server</b> is a server that a player creates and other players can join. The owner runs it with the <b>Admin Panel</b>.</p>

## Admin Panel

The **Admin Panel** is only for the owner of a private server. One of its options makes all [trolls](../items/trolls.md) and [items](../items/items.md) free for everyone in the server.

!!! info "In the rules"

    **Fake Donation** from the Admin Panel doesn't change any stats, so it isn't bannable ([c2](../community/rules.md#c2){ .mp-rule }). Covering the map because an Admin used a Size Change command on you isn't bannable either ([c6](../community/rules.md#c6){ .mp-rule }).
