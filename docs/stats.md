## Places in the game

Besides the main game, the experience has separate places for some kinds of servers:

| Place | What it is |
|---|---|
| **Meet People Across The World** | The main game, with voice chat servers |
| **NO-VOICECHAT** | Servers without voice chat |
| **[CUSTOM]** | Custom servers created by players |

The **18+ version** is a completely separate experience. See [Standard vs 18+ version](versions.md).
