# Game Versions

*Meet People Across The World* exists as **two separate Roblox experiences**, both made by [Nogo](nogo.md). This wiki covers the **18+ version**.

| | 18+ version | Standard version |
|---|---|---|
| **Who can play** | Adults (18+) only | Everyone allowed by Roblox |
| **Released** | 18 Oct 2024 | 1 Sep 2024 |
| **Visits** (Oct 2026) | about 33 million | about 76.5 million |
| **Average playtime** | about 19 minutes | about 10.5 minutes |
| **All-time player peak** | 1,758 (8 Aug 2026) | 2,988 (25 Jul 2026) |
| **Play** | [Open on Roblox](https://www.roblox.com/games/110570058234582) | [Open on Roblox](https://www.roblox.com/games/78699621133325) |

<small>Visits, playtime and peaks from Rolimons, checked 12 October 2026. Live numbers for the 18+ version are on [Game Stats](stats.md).</small>

## What carries over

The official description of **both** versions says:

> Gamepasses + Badges save between versions, Data does not save between versions

| | According to the game's description |
|---|---|
| Gamepasses | Saved between versions |
| Badges | Saved between versions |
| Everything else (for example coins) | Not saved: each version keeps its own data |

The 18+ version also has a **Gamepass Info** pass (buying it does nothing) whose description explains how this works: all its gamepasses are **linked to the standard version**, so a gamepass bought there carries over to the 18+ version.
