# Nogo

**Nogo** is the Roblox creator behind *Meet People Across The World*. Both versions of the game are published by the **Nogo** group, which has a verified badge and about **916,000 members** (October 2026). The group is owned by the user **nogo**, and its description simply says that everything in it is made by Nogo.
