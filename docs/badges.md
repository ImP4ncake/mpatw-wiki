# Badges

The game has **40 badges**. Almost every badge also unlocks a **title** and a **tag effect** (an emoji) that you can show off.

Badges are shared between the standard and the [18+ version](versions.md) of the game.

!!! info "Data source"

    Badge names and requirements come from the game's public badge list on Roblox (checked October 2026). Badges marked **[LIMITED]** can only be earned during an [event](features/events.md).

## Getting started

| Badge | How to get it | Reward |
|---|---|---|
| Welcome to Meet People Across The World! | Join the game for the first time | none |
| Invite a Friend! | Invite a friend to the game | "Friendly" title, 🤗 tag, 100 coins |
| Played in VR | Join the game in VR | "VR" title, 🤓 tag |
| Pet The Cat | Pet the cat | "Cat" and "Meow" titles, 🐾 tag |
| Pet The Dog | Pet the dog | "Dog" and "Woof" titles, 🦴 tag |
| Pianist | Play the piano | "Pianist" title, 🎹 tag |
| Coder | Redeem a code from the community server | "Coder" title, 👾 tag |
| Gifter | Gift anyone | "Gifter" title, 🎁 tag |
