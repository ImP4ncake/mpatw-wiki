# Combat Arenas

There are **six combat arenas**, each with its own weapon. Defeating **50 players** in an arena gives its badge.

| Arena | Badge |
|---|---|
| Sword Arena | Swordmaster |
| Gun Arena | Gunsmith |
| Boxing Arena | Boxer |
| Sniper Arena | Sniper |
| Bomb Arena | Arsonist |
| Greatsword Arena | Warrior |

!!! note

    The weapons in the **[Non-Lethal] Weapons Pack** gamepass are cosmetic only: they cannot defeat other players.
