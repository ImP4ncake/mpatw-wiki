# Map

The map is a big open area where players hang out, with lots of activities around it.

## Known locations

| Location | What you do there |
|---|---|
| [Draw Area](draw-area.md) | Draw with other players |
| [Drink Area](drink-area.md) | Make and serve drinks |
| [Combat Arenas](combat-arenas.md) | Six arenas: Sword, Gun, Boxing, Sniper, Bomb and Greatsword |
| [Chess](chess.md) | Play chess against other players |
| [Lottery](lottery.md) | Roll for prizes |
| [Country Trivia](country-trivia.md) | A quiz about countries |
| [AI Chatbot](ai-chatbot.md) | Talk to an AI |
| Piano | Play the piano (**Pianist** badge) |
| The cat and the dog | Pet them for the **Pet The Cat** and **Pet The Dog** badges |
| AFK World | A separate world where you earn coins while away (from the main screen) |
