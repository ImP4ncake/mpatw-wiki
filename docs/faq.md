# FAQ

??? question "Who made Meet People Across The World?"

    The game is made by **Nogo**, a Roblox group with a verified badge. It was released in **September 2024**.

??? question "Is this the official wiki?"

    No. This is a **fan-made wiki** and is not affiliated with Roblox Corporation or Nogo. For official news and rules, check the game's community server.

??? question "How many players fit in one server?"

    Up to **65 players** per server.

??? question "Can I play without voice chat?"

    Yes. The game has **no voice chat servers** as well as voice chat servers. See [Servers](features/servers.md).

??? question "How do I redeem codes?"

    Open the menu with the four squares icon on the left, go to **Settings** and type the code in the code box. The current list is on the [Codes](economy/codes.md) page.

??? question "Do my gamepasses work in the 18+ version?"

    Yes, gamepasses and badges are shared between the two versions. The rest of your data is not. See [Standard vs 18+ version](versions.md).

??? question "Can I set a different country?"

    The **Custom Country** gamepass lets players choose any country, but it is not for sale at the moment. See [Gamepasses](economy/gamepasses.md).

??? question "What is the rarest badge?"

    At the time of writing, **Sovereign** (finish #1 at the end of a Ranked Season) had been earned by only one player. **Explorer** (discover all 250 countries) is also extremely rare. See [Badges](badges.md).

??? question "Something on this wiki is wrong. What do I do?"

    Click the :lucide-pencil: edit button at the top of the page and fix it, or read [How to contribute](contributing.md).
