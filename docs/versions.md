# Standard vs 18+ version

*Meet People Across The World* exists as **two separate Roblox experiences** made by the same developer:

- the **standard version**, open to all players allowed by Roblox;
- an **18+ version**, for adult players only. The link to it is in the game's description on Roblox.

## What carries over

| | Shared between versions? |
|---|---|
| [Gamepasses](economy/gamepasses.md) | :lucide-check: Yes |
| [Badges](badges.md) | :lucide-check: Yes |
| Everything else you have saved | :lucide-x: No, each version has its own data |

So if you buy a gamepass in one version, you also have it in the other, but the rest of your saved progress is kept separately in each version.

!!! note "About this wiki"

    This wiki covers the **standard version**. If you notice a feature that works differently in the 18+ version, please mention it on the relevant page.
